# Multi-Factor Biometric Voter Authentication with Facial Liveness Detection for Polling Stations

## Project Summary
This project focuses on the System Analysis and Design (SAD) of a multi-factor biometric authentication architecture designed for physical polling station kiosks. By combining tokenized identification, guided image capture, an image quality gate, and facial liveness detection, the system mitigates high False Rejection Rates (FRR) and optimizes voter queue throughput.
