# User Stories

1. **As a voter**, I want real-time on-screen guidance when positioning my face so that I can easily complete my verification without failing due to poor lighting or improper distance angles.
2. **As a poll worker**, I want the system to provide clear, human-readable error codes (e.g., inadequate lighting vs. unmatched identity) when a voter fails authentication so I can efficiently assist them without compromising security rules.
3. **As an election administrator**, I want structured, anonymized audit logs of polling station check-ins so I can reconcile voter turnout numbers and audit system performance after the election concludes.
